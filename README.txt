# Thanvika N.J. — Personal Portfolio

A one-page, immersive portfolio inspired by the editorial/exploratory feel of the reference portfolio at priyanshi.si, but with original content and styling for Thanvika.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html` in a browser.
3. For the best experience, use VS Code's Live Server extension.

## Personalize before publishing

Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN`
- `https://github.com/YOUR-GITHUB`
- `Thanvika_NJ_Resume.pdf`

Put your resume PDF in this same folder.

Optional:
- Add your profile photo to `images/profile.jpg`.
- Replace the CSS project visuals with your own screenshots later.
